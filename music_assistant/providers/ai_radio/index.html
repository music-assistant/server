About AI Radio

AI Radio transforms a source playlist into a radio-style show by planning section flow, generating host text with LLM, synthesizing speech with TTS, and stitching results into playlist or live queue runs.

  • Playlist mode: creates a generated playlist with inserted AI segments.
  • Dynamic mode: keeps generating/injecting batches during playback.
  • Sections: reusable prompt modules shared across stations.
  • Flow rules: MUST / ALTERNATIVE / OPTIONAL determine section ordering.

  1. Load stations/sections: ai_radio/stations/list, ai_radio/sections/list.
  2. Start a run: ai_radio/start with mode: "playlist" or "dynamic".
  3. Poll status: ai_radio/status and render progress.phase.
  4. Stop when needed: ai_radio/stop.

Quick Guide (what a station is)

A station is your reusable AI Radio preset: source playlist + selected shared sections + flow rules + host/voice settings.

  • Station ID: internal key used by APIs and references.
  • Playback Device: player used in dynamic mode if no override is selected at run start.
  • Selected Sections: shared section definitions managed in the Sections menu.
  • ALTERNATIVE flow: picks exactly one choice from a weighted list for that slot.
  • OPTIONAL flow: independently tries to add one section if chance and guard rules pass.
  • Merge Section (ai_meta): used only when multiple between-song sections are selected for the same slot; it combines them into one spoken segment.
  • All values can be changed later.

Playback Flow Rules

Flow item types: MUST (always include), ALTERNATIVE (pick one weighted choice), OPTIONAL (independent chance + guard checks).

Merge behavior: if one slot ends up with multiple spoken sections and you have a section of type ai_meta, AI Radio uses that merge section to combine them into one natural segment.

Available Placeholders
<prev_songinfo> Previous track info (artist - title).
<next_songinfo> Next/current target track info (artist - title).
<very_next_songinfo> Track info after the next track (look-ahead).
<timestamp> Current local timestamp in the station timezone.
<weather_hourly> Hourly weather summary (when weather is configured).
<weather_daily> Daily weather summary (when weather is configured).
<section_drafts> Only for ai_meta merge sections: inserted section snippets.
